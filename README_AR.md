# ANAS PORTS PRO

**المطوّر:** Anas Khshan  
**الإصدار:** 1.0.0  
**الرخصة:** MIT

أداة Python خفيفة لفحص منافذ TCP على الأجهزة والخوادم التي تملكها أو لديك إذن صريح لاختبارها. تعرض المنافذ التي تقبل الاتصال، وتضيف أسماء شائعة للخدمات، ويمكنها حفظ تقرير JSON.

> **مهم:** لا تفحص أجهزة أو شبكات الآخرين دون إذن. الأداة لا تستغل الثغرات ولا تتجاوز تسجيل الدخول. فتح المنفذ لا يعني بالضرورة وجود ثغرة.

## المميزات

- فحص منافذ TCP مع تحديد عدد الاتصالات المتزامنة.
- فحص منافذ محددة أو قائمة أو نطاق.
- عرض النتائج والتقدم مباشرة في الطرفية.
- محاولة تسمية الخدمات الشائعة.
- حفظ النتائج بصيغة JSON.
- لا تحتاج إلى مكتبات Python خارجية.

## المتطلبات

- Python 3.9 أو أحدث.
- Kali Linux أو Debian أو Ubuntu أو macOS أو Windows.

## التثبيت على Kali Linux

```bash
sudo apt update
sudo apt install -y python3 python3-venv git
git clone https://github.com/YOUR-USERNAME/anas-ports-pro.git
cd anas-ports-pro
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
```

استبدل `YOUR-USERNAME` باسم حسابك على GitHub وغيّر اسم المستودع إذا اخترت اسمًا مختلفًا.

## أمثلة التشغيل

عرض المساعدة:

```bash
anas-ports --help
```

فحص المنافذ من 1 إلى 1024 على جهاز لديك إذن بفحصه:

```bash
anas-ports 192.168.1.10
```

فحص منافذ محددة:

```bash
anas-ports 192.168.1.10 -p 22,80,443
```

فحص نطاق وحفظ تقرير:

```bash
anas-ports 192.168.1.10 -p 1-2000 -o report.json
```

## الخيارات

- `-p` أو `--ports`: المنافذ أو النطاق.
- `-t` أو `--timeout`: مهلة الاتصال.
- `-w` أو `--workers`: عدد الاتصالات المتزامنة.
- `-o` أو `--output`: مسار حفظ تقرير JSON.

## حدود الأداة

- تدعم TCP فقط حاليًا، ولا تفحص UDP.
- أسماء الخدمات تقديرية بناءً على رقم المنفذ.
- المنفذ المفتوح ليس دليلًا وحده على وجود ثغرة.
- لا تتضمن استغلالًا آليًا أو تخمين كلمات المرور.
